# CryptoSchool v2.0 PRO (Kotlin + Jetpack Compose)

Улучшенная и расширенная версия приложения для обучения крипте с нуля:
- **Кликабельные слова прямо в тексте карточек (`HumanClickableStoryText`):** все сложные слова (`блокчейн`, `стейблкоин`, `сеть`, `сид-фраза`, `стакан`, `спред`, `газ`, `плечо`, `ликвидация`, `фандинг`, `стоп-лосс`) автоматически подчёркиваются прямо внутри текста и открывают карточку «На человеческом» при нажатии.
- **Интерактивный кликер по экрану биржи (`ExchangeScreenshotClicker`):** затемнённый интерфейс вывода Bybit/MEXC с пульсирующей кнопкой выбора сети.
- **15 подробных уроков + Босс-уровни** в конце каждого острова.
- **Прокачанная «Машина времени» + отдельный P2P-симулятор:** 3 исторических сценария («Ложный обвал», «Каскадный слив», «Импульсный пробой»), таймфреймы `15М`/`1Ч`, авто-ход свечей (`Play/Pause`), журнал сделок в профиле и симулятор P2P-сделки с защитой от фейкового PDF-чека.
